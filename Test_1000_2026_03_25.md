# NexiFuse Robust Expert:V2 Comprehensive Benchmark Report

**Date:** 2026-03-25
**Model:** NexiFuse Robust Expert v2
**Base:** DeepSeek-R1-Distill-Llama-8B + LoRA (rank=64, alpha=128)
**Training Data:** 41,019 formatted examples (45,346 raw → cleaned → validated → formatted)
**Training:** 2 epochs SFT on 8x NVIDIA L4, final loss 0.27
**Quantization:** Q4_K_M (4.6 GB GGUF)
**Inference:** Ollama on single NVIDIA L4 (22 GB VRAM)
**Benchmark:** 981 test prompts across 10 categories

## Conclusion

NexiFuse v2 achieves **A- overall** across 981 test prompts with **zero failures**. The 4.4x increase in training data and doubled LoRA capacity produced measurable improvements in:

1. **Response depth** (+10% avg length)
2. **Conceptual understanding** (C+ → B+, the biggest single improvement)
3. **Code completeness** (higher error handling rates in healthcare code)
4. **Coverage** (conceptual explanations and raw HL7 as new categories)

**Critical gaps** for V2.5: identity name consistency (17%), math accuracy (50%), and debugging response depth (6% short). These are addressable with targeted training data additions.

**The model is production-ready** for healthcare integration assistance, with strong performance in code generation, standards knowledge, and security compliance. GRPO/SimPO alignment (deferred from v2 due to GPU memory constraints) should further improve response quality in v2.5.
